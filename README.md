# 🚀 SpaceClicker

**SpaceClicker** is a cosmic, space-themed 2D clicker game built with Python and the Kivy framework. Embark on a journey through outer space, tap your way through cosmic objects, and enjoy a polished UI with smooth, lightweight animations.

---

## 🌟 Key Features

* 🛸 **Cosmic UI Design** - Immersive space atmosphere with stylized visual elements.
* ✨ **Smooth Animations** - Micro-interactions and fluid visual transitions that enhance the clicking experience.
* 🪐 **4 Unique Levels** - Advance through 4 distinct galactic stages, each featuring tougher cosmic targets.
* 📈 **Score Tracking** - Real-time progress monitoring as you smash your way to victory.

---

## 🛠️ Tech Stack

* **Language:** Python 
* **Framework:** Kivy (cross-platform GUI library)
* **Design Engine:** Kivy Language (`.kv` sheets for styles and layout)

---

## 💻 How to Run Locally

Follow these quick steps in your terminal to launch the game:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Eugene6/SpaceClicker.git
   cd SpaceClicker
   ```

2. **Create and activate a virtual environment:**
   ```bash
   python -m venv venv
   # For Windows:
   venv\Scripts\activate
   # For macOS/Linux:
   source venv/bin/activate
   ```

3. **Install the Kivy framework:**
   ```bash
   pip install kivy
   ```

4. **Start the game:**
   ```bash
   python clickerAnim.py
   ```
